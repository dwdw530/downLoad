## 已修复的打包启动故障

### 现象与错误

2026-09-11，用户反馈21:34生成的首版EXE“双击打不开”。实际复现为程序创建Tk主窗口时退出，错误如下：

```text
version conflict for package "Tcl": have 8.6.15, need exactly 8.6.12
```

当时源码测试和包内代码一致性检查已经通过，但它们没有覆盖打包程序启动时加载的原生DLL，因此不能据此认定EXE可用。

### 根因与修复

构建时虽然调用了py310_env中的python.exe，但父进程PATH仍包含Anaconda base。PyInstaller从base收集了8.6.15版Tcl/Tk DLL，同时打入py310_env中的8.6.12版Tcl/Tk脚本，运行时版本不匹配。

修复位于 `scripts/build_exe.py`：复制构建子进程的环境变量，将当前Python环境的 `sys.prefix/Library/bin` 放到该子进程PATH首位，再调用PyInstaller。此修改不改变系统PATH或用户的Conda安装。重新打包时只更新EXE和构建产物，保留dist中的配置、数据库和断点文件。
