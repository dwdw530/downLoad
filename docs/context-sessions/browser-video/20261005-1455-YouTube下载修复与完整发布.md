- 根因：原版能识别 HLS/DASH，但按钮、桥接和任务类型限制将其禁用；不能把“隐私模式访问”直接归因为需要登录。无痕扩展仍需浏览器手动授权，完整无痕下载链路未验证。

- `downloader/browser/bridge.py`、`core/download_engine.py`、`core/task_manager.py`、`database/db_manager.py`：复用现有队列、任务类型和字段接入 HLS/DASH，不新增数据库结构；生成 MP4 文件名，保留暂停/恢复路线。
