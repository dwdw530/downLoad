- `chunk_downloader.py`：新增 `ChunkDownloadError`（`transient` / `fatal` / `protocol`）与 `classify_status`，HTTP 状态码不再被吞；临时错误指数退避 1/2/4…（封顶 30s），等待期间可暂停/取消；`last_error` 把失败原因带回上层。

- 进度监控改为 `engine.chunk_progress` 内存聚合，不再每秒 `get_chunks()`；失败/完成/降级时清理，监控线程随之退出。
- 任务卡在重试期间显示 `下载中 · 正在重试 N 个分块（第 x 轮）`，有真实速度后自动收回。
- 新增 `downloader/ui/ctk_helpers.py` 的 `SafeToplevelMixin`，应用到 8 个对话框，替代原先散落的 4 份重复保护。

## 技术决策与注意事项

- 重试上限取“轮数 + 总时长”双保险，避免断网时任务无限挂住；常量集中在 `download_engine.py` 顶部。
- 不新增数据库状态 `retrying`：会牵动终态判定、并发槽位、UI 映射与重启纠偏；改为 `downloading` + 状态文案提示。
- 悬浮条用独立 `tk.Toplevel`（非 CTk）以完全控制 overrideredirect、色键透明与物理像素坐标；字体尺寸用负值（像素）避免二次换算。
- 拖动使用自记坐标 `_pos`，不回读 `winfo_x()`（WM 应用 geometry 是异步的，拖动中回读会被吸回原位）。
- 服务器不守 Range 的路径必须保留单线程兜底，`test_broken_range_server_falls_back_to_complete_single_download` 锁住该行为。
- CustomTkinter 退出阶段仍会自己 `print` 少量 `bad window path name`（DWM 分支），属三方库行为，未修改三方库。
