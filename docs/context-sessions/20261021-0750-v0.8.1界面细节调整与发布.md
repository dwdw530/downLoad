## 上下文摘要

用户提出三条界面意见：保存设置弹「已保存」很别扭、界面字太小、悬浮条太占地方。实施过程中出现两次方向偏差并被用户当场纠正：

1. 第一轮把「字太小」理解成全局字号问题，新增了 `ui/typography.py` 全局档位（normal/large/xlarge）、`apply_theme_fonts()` 改写 `ThemeManager.theme["CTkFont"]`、设置页「界面字号」选项，并放大了主窗口、设置页、各对话框的字体与按钮宽度。用户明确否定：**只要求放大左侧分类树，其他界面没让改**。
2. 第二轮只改侧栏，但沿用了「字体元组用负值（像素）」的口径，结果侧栏比原来更小——原生 `tkinter.Label` 的 font 元组正数是磅、负数是像素，`("Arial", 14)` 约 18.7px，而 `-18` 只有 18px 且中文字形不匹配。用户第二次指出「还是和原来一样大」。

最终方案：回滚所有全局字体改动与设置页字号选项，`typography.py` 只保留 `SIDEBAR_ITEM_FONT`（微软雅黑 UI 18pt）与 `SIDEBAR_HEADING_FONT`（17pt 加粗），侧栏 210→240，行高 22→31px。

## 关键坑

- **原生 Tk 与 CTk 的字号口径不同**：CTk 的 font 元组按像素（负数），原生 `tkinter.Label` 正数是磅。混用会让"放大"变成"缩小"。
- **`scripts/build_exe.py` 会清理 `dist`**：先打安装包再重建 EXE，会把 `dist/*-setup.exe` 一起删掉。正确顺序是先 `build_exe.py`，再 `build_installer.py`（或直接用 `build_installer.py --rebuild`）。
- **`smoke_installer.py` 需要 `output/playwright/sample.webm`**（`.gitignore` 内）。缺失时用随包 ffmpeg 生成：`ffmpeg -f lavfi -i testsrc=size=320x240:rate=10:duration=2 -c:v libvpx-vp9 -b:v 200k output/playwright/sample.webm`。
- **GitHub 资产上传走 `uploads.github.com`**，用 `api.github.com` 会 404；令牌经 `git credential fill` 取得，只通过 `curl --config -` 标准输入使用。
- `smoke_exe.py` 的工具栏按钮识别原先写死宽度 100，字号调整后需改为区间匹配（60~240 逻辑像素）。
