## 技术决策与注意事项

- 临时目录默认仍为程序目录下 `temp/`，不改变老用户行为；只有用户主动修改才换盘。
- 立即生效的边界：新任务和无数据排队任务马上换目录；有断点的任务继续用原目录。这样不需要跨盘搬移大文件，也不会让合并找不到分块。
- 同一磁盘时完成后仍走 `os.rename`，跨磁盘才复制；临时目录换到目标盘可消除整份复制。
- 程序本体、数据库和日志仍在安装盘，量级为 KB；不是本轮要解决的问题。
- 临时目录设在移动盘时，拔盘或盘符变化会让下载失败；目录校验只覆盖保存时刻。
- 未新增下载前空间检查；临时目录所在盘满仍会在下载中途失败。
