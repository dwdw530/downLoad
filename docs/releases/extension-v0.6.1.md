# daw 视频下载助手 0.6.1

> **状态：本版本未单独发布。** 其内容已并入 `v0.7.2 / 扩展 0.6.2`；下方“验证”段中关于测试与 dist 同步的描述与实际不符（详见 v0.7.2 说明）。

本次为 Chrome / Edge 浏览器插件更新，新增小红书视频笔记详情页的下载入口。桌面端需同时具备 `xhs` 能力（视频组件更新后的完整包），旧桌面端会提示"小红书模块尚未就绪"。

## 新增

- **小红书视频笔记**：在 `www.xiaohongshu.com/explore/<id>` 与 `/discovery/item/<id>`（含 SPA 弹层）的视频笔记页，悬浮面板与工具栏出现"小红书"站点条目，点一次进入桌面下载队列。文件名为 `小红书-<笔记ID>.mp4`。
- 页面状态读取官方播放器实际使用的签名 MP4 候选（排除小程序水印流），桌面端校验笔记 ID、`.xhscdn.com` 域名、h264/h265 编码、分辨率、无 `range` 参数及总时长后，经 `--load-info-json` + FFmpeg 合并，ffprobe 确认含音视频轨且时长一致后才发布。
- 清晰度上限沿用扩展设置（480/720/1080p）；源没有不高于上限的档位时明确报错，不擅自超限。
- `xsec_token` 等来源签名只留在浏览器内，不写入任务 URL、数据库或日志。

## 不支持

图文笔记、LivePhoto、`xhslink.com` 短链、合集批量、直播、字幕与无水印原画不在本次范围。签名地址过期时任务会失败并提示重新打开笔记页。

## 验证

- 源码与插件纯函数回归：`node --test tests/*.test.mjs` 全绿（含新增 xhsUrl / xhsNoteVideo 用例与脱敏页面状态样例）。
- 桌面端回归：`python -m pytest tests/ -q` 全绿（含新增 `tests/test_xhs_download.py`），既有断言零修改。
- 实网验收（面板条目、CDN 域名、时长、音视频轨）使用 `scripts/smoke_xhs.cjs`，需登录态，由用户/Codex 在发布前执行。

正式 `dist` 尚未随本日志更新；发布前需同步桌面端与扩展。
