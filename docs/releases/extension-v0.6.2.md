# 浏览器扩展 0.6.2：小红书真实页面结构适配

发布日期：2026-10-18。对应桌面版 v0.7.2。

## 修复

- 小红书 `video.media.stream` 的档位键改为 `EF4`/`EF5`/`EF6`/`EF7` 后，原实现只读 `h264`/`h265`，导致一条候选流都拿不到、面板始终提示「未获取笔记视频信息」。现改为按位置遍历所有档位，不依赖键名。
- `videoCodec` 现在存放的是档位名（如 `EF4`），原实现要求 `h264`/`h265` 会把所有候选丢弃。现只排除 `av1/av01/h266/vvc`。
- `masterUrl` 现为 `http://`，原实现强制 `https:`。现仅把协议替换为 `https://`，路径与签名参数不变。
- 竖屏视频（720×1280、1080×1920）此前被 `height <= 1080` 全部过滤。现按短边 `min(宽,高)` 判断档位。
- 只接受路径以 `.mp4` 结尾的完整文件；`.m4s` 分片排除。
- 删除按 `streamType` 数字猜测水印流的规则（真实取值与早期资料不符）。
- 补上小红书取信息兜底分支漏掉的 `await`，以及读取 Cookie/设置前缺失的第二次复核。

## 兼容

- 需要桌面版 v0.7.2 或更高（`ping` 的 `capabilities` 含 `xhs`），旧桌面会提示「小红书模块尚未就绪」。
- 其它站点与其它功能行为不变。
- 更新后必须在扩展管理页重新加载，并对已打开的小红书笔记页完整刷新。
