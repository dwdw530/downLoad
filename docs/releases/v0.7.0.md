# v0.7.0：浏览器右键普通链接下载

发布日期：2026-10-14。桌面版 v0.7.0，浏览器扩展 0.6.0。

## 新功能

- 对网页中的 HTTP/HTTPS 文件链接点击右键，选择“使用 daw 下载器下载此链接”，即可交给桌面下载器；桌面程序未运行时可自动启动。
- 普通点击、另存为和浏览器自带下载保持原有行为。右键入口独立于“识别视频”开关，普通文件不混入视频列表。
- 复用普通文件下载的队列、暂停恢复、同名保护和下载记录。支持从当前页面取得必要的 Cookie、User-Agent 和 Referer，并保留签名 URL 原串。
- 扩展弹窗新增独立的链接下载状态；连接中断且无法确认结果时提示“结果尚未确认”，不自动重发。

## 边界与兼容

- 点击前后核对标签页、iframe 和文档身份，防止导航切换后误用页面上下文。
- 视频页面和 HLS/DASH 清单继续使用原视频入口；普通文件分支不会绕过现有视频校验。
- 原抖音推荐流、YouTube、X、B 站及 HLS/DASH 能力保留。未知大小、零字节、POST 和特殊鉴权下载仍不在本次范围内。
- 状态与通知仅使用固定文案，不保存 URL、Cookie 或原始错误文本。

## 下载与升级

- 安装版：`daw-downloader-v0.7.0-windows-x64-setup.exe`，可选择安装路径并从系统卸载。
- 便携版：`daw-downloader-v0.7.0-windows-x64.zip`。
- 独立扩展：`daw-browser-extension-v0.6.0.zip`。
- 校验：安装包附 `.exe.sha256`，两个 ZIP 的 SHA256 见 `SHA256SUMS.txt`。

本功能需要同时更新桌面程序、BrowserBridge 和扩展。关闭下载器后安装到原目录；便携版只更新程序载荷，保留 `data/`、`temp/`、`downloads/`。在浏览器扩展管理页重新加载 `chrome-extension/`，接受新增的右键菜单与通知权限，并完整刷新已打开的网页。

仅更新扩展、仍使用旧版桌面程序时，会提示升级，不会把普通文件送进旧视频分支。历史 Release、标签和附件保持原样。
