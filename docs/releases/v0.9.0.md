# v0.9.0：下载健壮性、全局限速与悬浮条真透明

发布日期：2026-10-21。桌面版 v0.9.0，浏览器扩展 0.6.2（未改动）。

本版集中在三件事：**下不下来的场景说清楚原因并尽量失败得早**、**限速改成真正的总量上限**、**悬浮条边缘不再有毛刺**。

## 本次改动

### 1. 添加任务不再卡界面，失败会说清原因

以前单条链接是在界面线程里同步探测，站点慢的时候窗口假死；失败只有一句「任务添加失败」，403、404、登录页、断网看起来完全一样。

- 单条链接和批量一样走后台探测，探测期间窗口可正常拖动和操作。
- 失败原因按类型给出提示：

| 情况 | 提示 |
|------|------|
| 超时 / 连不上 / DNS 解析失败 | 提示检查网络或代理设置 |
| 404 / 410 等 4xx | `服务器返回 HTTP 404`，提示链接可能失效 |
| 401 / 403 且返回网页 | 提示可能是登录页，需先在浏览器登录 |
| 5xx | 提示服务器暂时出错，稍后重试 |
| 服务器不给大小 | 提示当前版本暂不支持未知大小下载 |
| 磁盘空间不足 | 直接给出还差多少 |

- 单条添加成功不再弹确认框，改为状态栏闪 3 秒提示（与设置保存一致）；批量添加仍汇总成一个结果框。

### 2. 文件名优先取服务器给的名字

以前一律从 URL 末段取名，`https://host/file.php?id=123` 会存成 `file.php`，重定向下载还会存成 `redirect` 之类的名字。

现在按优先级取名：**添加时手填 > `Content-Disposition`（含 `filename*=UTF-8''…` 中文） > 重定向后的真实地址 > 原始地址**。

- 服务器返回登录页（`text/html`）时**不采用**它给的文件名，避免存成 `login.html`。
- 带路径的名字只取最后一段（`../../evil.exe` → `evil.exe`），保留名、ADS、控制字符一律拒绝；超长文件名保留扩展名截断到 120 字符。

### 3. 下载前和合并前检查磁盘空间

以前是全无预检，几十 GB 的包下到 90% 才发现盘满。

- 添加任务时估算峰值占用：分块写临时目录、合并副本写目标目录，**同盘时按两倍算**，跨盘各算一份。不足直接拒绝并提示 `还差 X`。
- 合并前再核对一次目标盘。不足时任务置为**已暂停**（不是失败），分块与临时文件全部保留，腾出空间后点「继续」即可完成。
- 拿不到容量的路径（网络盘、权限不足、盘符变化）**一律放行**，不会因为新检查把正常下载拦死。

### 4. 限速语义变更：从「每任务」改成「总量」

**这是本版唯一有用户感知的行为变更。**

以前 `speed_limit` 是每个任务各限一份，并发 3 个任务实际就是 3 倍；现在改成**所有普通文件任务合计**的上限，这才符合「限速」的原意。

- 设置页标签由「速度限制(KB/s)」改为「**总速度上限(KB/s)**」，提示「所有任务合计，0 表示不限速」。
- 运行中修改立即生效，不需要重启任务。
- 视频任务（yt-dlp）仍按单任务限速，不受这个总量约束。
- 同时修掉限速器的一个实现缺陷：原实现在等待期间会重复累计额度，实测速度约为设定值的两倍。

### 5. 新增「↻ 重试失败」按钮

工具栏在「继续全部」右侧新增「↻ 重试失败」，一次重试所有失败任务。

- 失败任务 ≥10 个时先弹确认，避免误触。
- 在后台执行（每条重试都要重新探测资源），不阻塞界面；结果在状态栏提示。
- 无失败任务时只提示，不弹框。

### 6. 状态栏统计改数据库聚合

状态栏每秒原本要执行两次全表查询。现在改成 `GROUP BY status` 计状态数 + `SUM(speed)` 算总速度，任务数上百时不再白耗 IO。数据库短暂被占用时沿用上一次的数字，不再每秒抛异常。

### 7. 启动清理残留临时文件

崩溃、强杀、断电后，`temp/` 里会永久残留分块临时文件。现在启动后自动清扫一次，只删同时满足以下条件的文件：

1. 位于临时目录顶层；
2. 文件名严格是 `{任务ID}.partN` / `{任务ID}.tmp`；
3. 数据库里没有任何任务或分块引用它；
4. 修改时间早于 7 天。

视频中间目录（`temp/<平台>/<任务ID>/`）本轮不处理，避免误删 yt-dlp 的中间文件。清理后状态栏提示回收数量。

### 8. 桌面悬浮条：真正的逐像素透明

上一版的圆角是硬边台阶（Tk Canvas 不做抗锯齿），v0.8.1 之后的一版修复又引入了色键透明过渡环，浅色壁纸下会出现一圈锯齿黑边。

本版改成 Windows 分层窗口 `UpdateLayeredWindow` + 32 位预乘位图，实现**真正的逐像素 alpha**：

- 圆角外侧完全透明，边缘像素半透明，与桌面任何壁纸自然混合，没有色键过渡环。
- 整条卡片在 4 倍尺寸绘制后降采样，圆角 alpha 过渡从 4 级提升到 89 级。
- 圆角外区域点击自动穿透到下层窗口（色键方案做不到）。
- 修掉一个显示缺陷：空闲状态下底部原本会画一条贴底的绿色实线，现在只显示中性色基线。
- **尺寸、字号、右键菜单项与上一版完全一致**，仅渲染方式变化。

## 行为说明与边界

- 桌面版从 v0.8.1 升级无需迁移：`data/config.json`、`data/downloads.db`、断点和已下载文件都不受影响。
- **限速数值会「变慢」是预期行为**：以前填 1 MB/s 开 3 个任务实际能跑到 3 MB/s，现在合计 1 MB/s。想要原来那种效果请把数值乘以并发数，或填 0 不限速。
- 未知大小 / 零字节文件仍然拒绝，只是提示更明确了；这类下载需要单独的改造。
- 浏览器扩展仍为 0.6.2，本版没有扩展改动，只更新桌面程序时不需要重新加载扩展；升级桌面端后需重启下载器。
- 视频平台链路（YouTube / B 站 / 抖音 / 小红书 / X）与 v0.8.1 一致，未改动。

## 下载与升级

- 安装版：`daw-downloader-v0.9.0-windows-x64-setup.exe`，可选择安装路径并从系统卸载。
- 便携版：`daw-downloader-v0.9.0-windows-x64.zip`。
- 独立扩展：`daw-browser-extension-v0.6.2.zip`（未改动）。
- 校验：安装包附 `.exe.sha256`，ZIP 的 SHA256 见 `SHA256SUMS.txt`。

升级前请正常退出下载器及托盘进程，再运行新版安装包并沿用原安装目录。配置、数据库、下载记录和断点均保留。

## 已知边界

- 悬浮条在非 Windows 平台只保证窗口与位置逻辑，像素推送会跳过（不影响打包产物）。
- 悬浮条未做投影效果，也未验证多显示器混合 DPI 缩放（150% + 200% 混接）。
- 「重试失败」不区分致命/临时错误，源文件已删除的任务会快速再失败一次。
- 孤儿清扫不处理目标下载目录里强杀残留的合并临时副本。
