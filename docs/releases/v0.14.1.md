# v0.14.1 · 移动盘未连接时的错误提示修复

## 本版更新

- 下载目录或临时目录所在磁盘不可用时，明确显示“下载目录所在磁盘不可用”或“临时目录所在磁盘不可用”，不再误报“网络连接失败”。
- 添加、开始或继续下载前检查实际保存位置、当前临时盘和旧分块仍使用的临时盘。缺盘时停止启动，不联网、不自动换盘，也不清除已有断点；磁盘在线但普通子目录不存在时仍允许自动创建。
- 视频任务在启动工具前再次检查磁盘；本地异常不再套用含网络故障的通用文案。旧任务中的“请检查网络、磁盘或下载组件”只是排查建议，不再被当作已确认的网络故障。
- 浏览器扩展 **0.6.2 内容不变**。侧栏滚动、窗口显示稳定性、下载安全、续传身份校验、Retry-After、限速、校验、透明度、悬浮条与完成后动作保持原有规则。

插回 U 盘或移动硬盘并确认恢复原盘符后可重试。修改默认下载目录只影响新任务；旧任务要更换保存位置，需要重新添加。保留断点不代表跳过原资源身份校验。

安装包旁的 `.exe.sha256` 校验安装包；`SHA256SUMS.txt` 校验两个 ZIP。GitHub 自动生成的 Source code 是源码，不是可直接运行的发布包。历史 Release、标签与附件保持原样。

## 验证与边界

源码已完成 29 项针对性测试，覆盖缺失目标盘、当前临时盘、旧分块盘的添加/启动/继续拒绝、断点保留、视频异常及错误分类。真实 Tk 卡片和详情提示已核验，正常新建目录完成 4096 字节本地 HTTP 下载并逐字节一致。

本轮没有重新执行完整 Python 套件、物理混合 DPI 或所有公开网站长期下载；本地 HTTP 不替代这些场景。该修复覆盖启动时磁盘不可用和视频异常后的磁盘复查，不保证下载中突然拔盘可以无损继续。
