# v0.13.0 · 透明度、悬浮条精修与完成后退出

## 本版更新

- **主窗口不透明度**：设置新增「外观」页，可调 60%–100%，默认 100%。文字随主窗口一起变淡，独立设置、详情和确认窗口保持不透明。
- **悬浮条背景不透明度**：可调 30%–100%，文字和已填充进度保持清晰；关闭悬浮条时预览不会擅自开启它。
- **设置闭环**：滑块实时预览但不改配置，取消/关闭恢复；保存或输入校验失败恢复原透明度。恢复默认成功后回退基线同步更新，重启保留保存值。
- **悬浮条精修**：修复 Windows 分层窗口的预乘 BGRa 格式和 GDI 句柄释放，去双亮边、进度硬高光及曲线大端点；保留完整 280×118 / 迷你 158×34 逻辑尺寸、字体、拖动贴边和全部右键菜单项。
- **完成后退出**：「其他」页新增互斥选项“不操作 / 退出下载器 / 关闭电脑”。退出有 10 秒可取消倒计时，关机保留 60 秒，打开文件/文件夹仍独立选择。
- **误退出保护**：只跟踪本轮实际参与的任务；本轮失败、校验失败、暂停、取消、删除和未结束后台工作不自动退出。历史失败不永久阻挡新成功轮次，新增/重试、动作切换、旧事件与模态窗口均经过复核，最终原子关闭入口再正常清理程序。

## 升级

正式版只支持 64 位 Windows。升级前正常退出下载器和旧 BrowserBridge，使用新版安装包沿用原路径，或完整替换便携版发布文件。不要删除 `data/`、`temp/`、下载文件或断点。

扩展 **0.6.2 内容不变**，无需重新安装扩展；本次应更新主程序和桥接，再重启下载器和浏览器。全局 DPI、侧栏 13 逻辑像素、240px 宽度、下载/续传/哈希/限速、浏览器安全协议及已有功能保持。
