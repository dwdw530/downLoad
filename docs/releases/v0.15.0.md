# v0.15.0 · 音频、字幕、高清选项与简洁更新检查

## 本版更新

- 视频下载继续保留，新增“仅音频”：可保留源音频格式，或转换成 MP3。最终扩展名、保存位置与任务记录保持一致，暂停、重启和重试后保留所选模式。
- 新增已有字幕下载，可选中文、英文、两者或全部可用语言，保存为媒体文件旁的 SRT。没有获取到全部所选字幕时明确提示，不凭空生成字幕，也不覆盖已有字幕文件。
- 清晰度增加最高 1440p、2160p 和最高可用画质；保留 MP4 兼容模式，新增 MKV 源画质优先。以源资源实际格式为准，不放大或重编码视频，任务卡片和详情显示实际分辨率、编码及字幕结果。
- 新增主窗口“检查更新”：后台读取正式版本及更新说明，只提供官方下载入口，不自动安装或覆盖程序。自动查询受限时使用紧凑提示，隐藏空白说明框和无关安装文案；成功获取新版后再展示更新说明与升级提示。
- 视频输出选项随任务落库，请求编号包含模式、清晰度、格式与字幕选择，避免不同选项误用旧任务回执；主文件与字幕共同分配未占用名称，发布时保留非覆盖保护。
- 程序、安装器与发布命令共用版本来源，桌面版本为 **v0.15.0**，浏览器扩展为 **0.7.0**。

## 使用边界

- 视频清晰度是上限，不保证源站提供该档位；原视频只有 1080p 时不会变成 4K。MKV 源画质优先可能使用旧播放器不支持的编码。
- 仅音频需要源媒体实际包含音轨；源格式通常避免重新压缩，转换 MP3 会重新编码。字幕只下载源站可访问的人工或自动字幕，不做语音识别。
- GitHub 网页与自动更新接口是不同的访问入口；自动查询可能受限，仍可通过“查看发布页”手动查看版本。
- 播放列表批量、直播录制、DRM 绕过、会员或登录权限绕过不在本版范围。公开站点的资源权限和签名有效期仍可能影响下载。
