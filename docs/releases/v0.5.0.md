# daw下载器 v0.5.0

Windows x64，提供安装包与便携版，浏览器扩展仍为 0.5.0（本版未改动扩展）。本版在 v0.4.0 的界面上新增两个功能：**双击任务卡片查看实时速度曲线详情窗**，以及**剪贴板监视**（复制链接自动弹出添加提示）。其余下载、队列、视频链路与扩展均与 v0.4.0 相同。

## 下载哪个文件

- **需要选择安装路径、桌面快捷方式和系统卸载**：[下载安装包 EXE](https://github.com/dwdw530/downLoad/releases/download/v0.5.0/daw-downloader-v0.5.0-windows-x64-setup.exe)，约 148.5 MiB。包含完整运行环境和视频组件，无需安装 Python。相邻的 `.exe.sha256` 文件用于校验此安装包。
- **需要便携版或覆盖原解压目录升级**：`daw-downloader-v0.5.0-windows-x64.zip`。包含下载器、BrowserBridge、浏览器扩展、yt-dlp、FFmpeg/ffprobe、Node 和第三方许可证。
- `daw-browser-extension-v0.5.0.zip`：独立浏览器扩展包。本版扩展与 v0.4.0 完全相同，只升级桌面程序时无需重新安装扩展。
- `SHA256SUMS.txt`：上述两个 ZIP 的 SHA256 校验值。
- GitHub 自动生成的 `Source code` 是源码，不是 Windows 运行包。窗口标题里的旧版号 `v1.0` 仍保留，本次发布标识为 `v0.5.0`。

## 本次变化

### 1. 任务详情窗（速度曲线）

- **双击任务卡片**（文件名、进度条等空白区域）打开任务详情窗：状态、进度条、已下载/总大小、剩余时间、当前/峰值/平均速度，以及最近约 3 分钟的实时速度曲线。
- 曲线每秒采样一次，暂停/完成后冻结；仅内存记录，重启后清空。删除任务时详情窗自动关闭。
- 详情窗非模态，可以边下载边看；每个任务同时只开一个。

### 2. 剪贴板监视

- 复制单个 `http(s)://` 链接时自动弹出小提示窗，点「添加任务」进入标准添加框（链接已预填），保存目录、哈希校验、稍后下载照常可用。
- 弹窗不抢键盘焦点；「忽略此站点」把该域名写入忽略列表并持久化（含其子域名）。
- 同一次剪贴板内容只提示一次；多行文本、非 http(s) 链接不触发；主窗口在托盘或模态对话框打开时不弹，过后也不补弹。
- 可在 **设置 → 剪贴板监视** 关闭该功能或编辑忽略站点列表（`clipboard_monitor_enabled` / `clipboard_ignore_hosts`）。

### 其它

- 修复设置对话框快速保存关闭时可能偶发的 `bad window path name` 报错（CTk 延迟标题栏回调时序）。

队列调度、多线程分块、断点续传、限速、代理、批量添加、稍后下载、任务筛选、历史记录、托盘，以及抖音详情页完整 MP4、X 首页悬浮下载、YouTube、B 站、HLS/DASH 与直链下载等能力与 v0.4.0 相同，未做改动。

## 使用与升级

安装版：运行 `*-setup.exe`，选择当前用户有写入权限的安装目录。升级前退出下载器（含托盘进程），沿用原目录即可。卸载从 Windows「设置 → 应用 → 已安装的应用」进行，保留配置、下载记录、下载文件和断点。浏览器扩展仍需手动加载安装目录中的 `chrome-extension`。完整构建、安装、升级与卸载步骤见 [安装包操作说明](https://github.com/dwdw530/downLoad/blob/main/docs/INSTALLER.md)。

便携版：

1. 升级前正常退出下载器，包括托盘进程。将完整包解压到原安装目录，保留原 `data`、`temp`、`downloads`。
2. 本版未改动扩展，原有浏览器集成无需重装；若移动了安装位置，需要重新运行同目录 `install_browser_bridge.cmd` 注册桥接。
3. 升级桌面程序后建议对已打开的 X、YouTube、B 站、抖音标签页按 F5 / Ctrl+F5 完整刷新，避免旧页面脚本残留导致悬浮按钮异常。

发布包不包含用户配置、数据库、Cookie、下载文件、断点文件或本机桥接注册清单。
