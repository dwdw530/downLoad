# v0.8.0：桌面速度悬浮条，失败分块单独重试

发布日期：2026-10-21。桌面版 v0.8.0，浏览器扩展 0.6.2（未改动）。

## 本次改动

### 桌面悬浮条（默认关闭）

在「设置 → 其他 → 显示可拖动的速度悬浮条」开启后，桌面会出现一条置顶小窗：

- 实时显示总速度、当前任务百分比、进度条、文件名、剩余时间和最近一分钟的速度曲线。
- 按住卡片任意位置即可拖动；松手后靠近屏幕边缘会自动吸附，位置按物理像素保存，多显示器与高 DPI 下重启仍回到原处。
- 双击悬浮条显示主窗口；右键菜单可暂停全部、继续全部、打开设置、隐藏悬浮条或退出程序。
- 从右键菜单隐藏后，该开关同时置为关闭，下次启动不再自动弹出。
- 悬浮条每秒读一次任务状态，只读数据、不参与下载调度；主窗口切换到深色/浅色主题时同步换色。

### 失败分块单独重试，不再整份作废

以前任意一个分块重试用尽，程序会删除**所有**已下载分块、进度归零后改单线程从头重下。大文件下到九成时一个分块出错，等于整份白下。现在按失败原因分三类处理：

| 失败原因 | 处理方式 |
|----------|----------|
| 超时、连接中断、5xx、429 | 指数退避（1s / 3s / 10s）后只重试失败的那几块，已完成的分块及其临时文件原样保留；最多 3 轮，总时长上限 5 分钟 |
| 403 / 404 / 410 / 文件版本变化 | 立即失败并显示真实原因，不浪费时间重试；已下载的数据全部保留，点「继续」可接着跑 |
| 服务器不守 Range（返回 200、Content-Range 不符） | 仍然自动降级为单线程，从零重下（这类源本来就没有可拼接的分块） |

- 错误分类放在 `ChunkDownloadError`：`transient` / `fatal` / `protocol`，HTTP 状态码不再被吞掉，失败原因会显示在任务卡和错误信息里。
- 单次分块内部的尝试次数仍取配置 `retry_times`，分块之间的轮次与总时长上限是 `download_engine.py` 顶部的常量。
- 重试期间任务卡显示 `下载中 · 正在重试 N 个分块（第 x 轮）`，数据恢复流动后自动收回。

### 进度监控改为内存聚合

- 监控线程不再每秒查询一次分块表，直接对内存中的分块字节数求和后落库；多任务并发时减少数据库读放大。
- 任务失败、完成或降级时同步清理内存进度表，监控线程随之退出，不会残留后台写入。

### 修复对话框关闭后的延迟回调异常

CustomTkinter 会在建窗后把标题栏配色和焦点恢复排进事件队列。对话框“点确定就销毁”时，这些回调会打已销毁的窗口，抛 `bad window path name`。现新增 `downloader/ui/ctk_helpers.py` 的 `SafeToplevelMixin`，统一应用到设置、历史、添加任务、删除、关闭确认、关机确认、剪贴板提示和任务详情共 8 个对话框。

## 行为说明与边界

- 悬浮条默认关闭，不改变存量用户界面；开关与位置写入 `config.json` 的 `ui_float_bar_enabled` / `ui_float_bar_pos`。
- 悬浮条使用色键透明实现圆角，未引入新依赖（无需 pywin32）。
- 分块重试的“已完成数据保留”与原有的续传校验一致：重新启动时若资源版本（ETag / Last-Modified）变化，仍会安全重下，不拼接不同版本。
- 服务器不守 Range 时依旧走单线程兜底，这是既有行为，未放宽。
- 浏览器扩展仍为 0.6.2，本版没有扩展改动；只更新桌面程序时不需要重新加载扩展。升级桌面端后需重启下载器。

## 下载与升级

- 安装版：`daw-downloader-v0.8.0-windows-x64-setup.exe`，可选择安装路径并从系统卸载。
- 便携版：`daw-downloader-v0.8.0-windows-x64.zip`。
- 独立扩展：`daw-browser-extension-v0.6.2.zip`（未改动）。
- 校验：安装包附 `.exe.sha256`，ZIP 的 SHA256 见 `SHA256SUMS.txt`。

升级前请正常退出下载器及托盘进程，再运行新版安装包并沿用原安装目录。配置、数据库、下载记录和断点均保留。

## 验证

- `py310_env` 全量：`python -B -m unittest discover -s tests` → 385 项通过（GUI 182 项）。
- 新增用例覆盖：5xx 只重试失败分块（4 个分块共 5 次请求）、404 立即失败且保留已完成分块、重试耗尽后保留部分数据且不降级单线程、重试提示显示与自动收回、悬浮条显示/隐藏/拖动落盘/开关即时生效。
- `scripts/smoke_exe.py` 与 `scripts/smoke_installer.py` 通过记录见 `docs/INSTALLER.md`。
- 构建前后核对 `dist/data`、`dist/temp` 哈希一致，未改动用户配置、数据库与断点。

## 已知边界

- 悬浮条不支持鼠标点击穿透（需要额外依赖），也未提供“仅显示图标”的迷你形态。
- 分块仍是创建时静态等分，慢分块不会动态切分给空闲线程。
- 限速为全局单值并在分块间均分，尚不支持每任务独立限速。
- 该版不包含站点适配变更，YouTube / B 站 / 抖音 / 小红书 / X 的行为与 v0.7.3 一致。
