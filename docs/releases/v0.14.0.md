# v0.14.0 · 侧栏滚动与窗口显示稳定性

## 本版更新

- **左侧分类栏可滚动**：支持鼠标滚轮与拖动滚动条，内容溢出时才显示滚动条；站点增删和窗口缩放后同步范围，内容不足一屏时归零。
- **左右两栏独立滚动**：侧栏滚轮不会带动任务列表；滚到末尾的站点仍可点击筛选。保留 240 逻辑像素侧栏、13 逻辑像素字号、分类计数、搜索、多选与已有筛选规则。
- **功能窗口显示更稳定**：修复添加、设置、历史等窗口为刷新标题栏而再次隐藏、显示的问题。已显示窗口直接更新 Windows DWM 标题栏属性，首次初始化、窗口关闭保护、字体、布局和配色保持。
- 浏览器扩展 **0.6.2 内容不变**；下载、续传、重试、限速、校验、透明度、悬浮条与完成后动作保持原有规则。本版不增加定时下载、失效链接更新或列表分页。
