# daw下载器 v0.6.0

Windows x64，提供安装包与便携版，浏览器扩展仍为 0.5.0（本版未改动扩展）。本版继续按 IDM 的界面思路补齐任务管理入口：**左侧分类树**、**任务右键菜单与手动排序**，以及**主题切换（深色 / 浅色 / 跟随系统）**。下载引擎、队列与视频链路均与 v0.5.0 相同。

## 下载哪个文件

- **需要选择安装路径、桌面快捷方式和系统卸载**：[下载安装包 EXE](https://github.com/dwdw530/downLoad/releases/download/v0.6.0/daw-downloader-v0.6.0-windows-x64-setup.exe)，约 148.5 MiB。包含完整运行环境和视频组件，无需安装 Python。相邻的 `.exe.sha256` 文件用于校验此安装包。
- **需要便携版或覆盖原解压目录升级**：`daw-downloader-v0.6.0-windows-x64.zip`。包含下载器、BrowserBridge、浏览器扩展、yt-dlp、FFmpeg/ffprobe、Node 和第三方许可证。
- `daw-browser-extension-v0.5.0.zip`：独立浏览器扩展包。本版扩展与 v0.5.0 完全相同，只升级桌面程序时无需重新安装扩展。
- `SHA256SUMS.txt`：上述两个 ZIP 的 SHA256 校验值。
- GitHub 自动生成的 `Source code` 是源码，不是 Windows 运行包。窗口标题里的旧版号 `v1.0` 仍保留，本次发布标识为 `v0.6.0`。

## 本次变化

### 1. 左侧分类树

- 主窗口改为左右分栏，左侧按三组分类筛选任务，括号里是当前数量：
  - **状态**：全部 / 下载中 / 等待中 / 已完成 / 失败
  - **类型**：视频 / 音频 / 文档 / 压缩包 / 程序 / 其他（按扩展名判断）
  - **站点**：按链接主机名自动生成（保留 `dl.example.com` 这类子域），随任务增删更新
- 分类与搜索、「隐藏已完成」叠加生效；选中项写入 `config.json` 的 `ui_active_category`，重启后保持。
- 选中的站点下不再有任务时，自动回退到「全部」，避免列表一直空白。

### 2. 任务右键菜单与手动排序

- 右键任务卡片弹出：**开始/暂停**、**打开文件**、**打开所在文件夹**、**复制下载链接**、**上移**、**置顶**、**删除任务**；当前不可用的项自动置灰。
- 「上移/置顶」改写任务顺序并写入数据库（`download_tasks.list_order`），重启后保留，**等待中的任务按该顺序依次出队**。
- 「复制下载链接」不会触发剪贴板监视的添加提示（同一次内容只提示一次）。

### 3. 主题切换

- **设置 → 主题**可选 **深色 / 浅色 / 跟随系统**（默认深色），保存后立即生效并写入 `ui_appearance_mode`。
- 「跟随系统」跟随 Windows 的应用主题设置。

### 其它

- 分类树、分类项与分组标题的字号对齐右侧正文，侧栏加宽到 210px。
- 修复切换到浅色主题（含「跟随系统」或系统主题变化）后，左侧栏仍停留在旧主题配色的问题。
- 升级旧版本数据时自动为任务表补充排序列，**原有任务顺序不变**，新任务仍追加在列表末尾。
- 分类树改用原生控件实现，避免大量界面元素反复创建时拖慢事件循环（本版内部修复，不影响使用）。

队列调度、多线程分块、断点续传、限速、代理、批量添加、稍后下载、任务搜索与隐藏已完成、速度曲线详情窗、剪贴板监视、历史记录、托盘，以及抖音详情页完整 MP4、X 首页悬浮下载、YouTube、B 站、HLS/DASH 与直链下载等能力与 v0.5.0 相同，未做改动。

## 使用与升级

安装版：运行 `*-setup.exe`，选择当前用户有写入权限的安装目录。升级前退出下载器（含托盘进程），沿用原目录即可，原有任务与断点保留。卸载从 Windows「设置 → 应用 → 已安装的应用」进行，保留配置、下载记录、下载文件和断点。浏览器扩展仍需手动加载安装目录中的 `chrome-extension`。完整构建、安装、升级与卸载步骤见 [安装包操作说明](https://github.com/dwdw530/downLoad/blob/main/docs/INSTALLER.md)。

便携版：

1. 升级前正常退出下载器，包括托盘进程。将完整包解压到原安装目录，保留原 `data`、`temp`、`downloads`。
2. 本版未改动扩展，原有浏览器集成无需重装；若移动了安装位置，需要重新运行同目录 `install_browser_bridge.cmd` 注册桥接。
3. 升级桌面程序后建议对已打开的 X、YouTube、B 站、抖音标签页按 F5 / Ctrl+F5 完整刷新，避免旧页面脚本残留导致悬浮按钮异常。

发布包不包含用户配置、数据库、Cookie、下载文件、断点文件或本机桥接注册清单。
