# v0.16.0 · 悬浮条重设计与任务界面改进

## 本版更新

- 迷你悬浮条改为胶囊卡面，以分层的速度数字和单位、当前任务进度环及百分比显示下载状态；完整模式将总速度、当前文件进度、速度曲线和剩余时间分层，窗口大小不扩大。
- 悬浮条主值仍为所有下载中任务的总速度，进度和文件名表示当前任务；剩余时间只使用当前任务速度，不再借用其他任务的速度做偏乐观估算。
- 未知或零总量不编造 `0%`；等待、暂停、校验、下载失败和校验失败有独立提示。悬停说明数据口径和原有操作，不抢焦点、不保存设置，拖动或隐藏时收回。
- 保留悬浮条拖动贴边、位置记忆、双击显示主窗口、原右键菜单及字号、主题与透明度预览/取消/隐藏重显。
- 任务卡片与详情新增预计完成时刻。仅估算当前任务剩余传输，不包含后续合并、转码或校验；总量或速度未知、任务暂停等情况使用占位提示。
- 新增批量复制当前可见勾选任务的下载链接，保留原链接、重复链接和签名参数，不附加媒体选项，也不改变任务或断点。
- 修复主窗口切换主题时的隐藏/重显流程，避免连带隐藏已打开的详情窗口。
- 仅音频、已有字幕、高清选项与普通文件/视频下载能力保持；浏览器扩展仍为 **0.7.0**，本版不改扩展内容。

## 使用边界

- 预计完成时刻和剩余时间是基于当前速度的估算，速度变化会影响结果，不代表媒体后处理或校验结束时间。
- 不新增下载调度、数据库结构、浏览器协议或后台自动安装功能。播放列表批量、直播录制和 DRM/权限绕过不在本版范围。
