# v0.8.1：界面细节调整

发布日期：2026-10-21。桌面版 v0.8.1，浏览器扩展 0.6.2（未改动）。

本版没有下载链路改动，只修正上一版留下的界面问题。

## 本次改动

### 左侧分类树字号放大

- 分类项改为微软雅黑 UI 18pt，分组标题（分类 / 状态 / 类型 / 站点）17pt 加粗，侧栏宽度 210 → 240、行内边距加大，长分类名不再被挤掉。
- 上一版把侧栏字体写成负值（像素口径）反而比原来的 `Arial 14pt` 更小，这版按原生 Tk 的磅值口径修正：行高从 22px 提到 31px。
- 其它界面（工具栏、任务卡片、状态栏、设置页、各对话框）字体保持原样，未做统一定制。

### 保存设置不再弹「已保存」

- 点「保存」后设置框直接关闭，主窗口状态栏闪 3 秒「设置已保存」，之后自动恢复总速度统计，不再需要多余地点一次「确定」。
- 「恢复默认」改为在按钮旁就地提示 2 秒，不弹窗。
- 仅错误路径继续弹窗：下载目录或临时目录为空、临时目录不可写、超时或限速不是数字、配置文件写入失败。失败必须让用户停下来处理。

### 桌面悬浮条新增迷你模式，完整模式进一步收窄

- 完整模式：348×160 → **280×118**，保留速度、百分比、进度条、文件名、剩余时间和一分钟速度曲线。
- 迷你模式：**158×34**，只留状态点、速度和百分比，底部一条细进度线。
- 切换入口：「设置 → 其他 → 悬浮条样式」（完整 / 迷你），或悬浮条右键菜单勾选「迷你模式」。选择写入 `config.json` 的 `ui_float_bar_mode`，重启后保持；切换时位置保留并重新夹进屏幕内。
- 两种模式的字号随尺寸一起下调，避免小条子里文字占掉一半。

## 行为说明与边界

- 桌面版从 v0.8.0 升级无需迁移：`data/config.json`、`data/downloads.db`、断点和下载文件都不受影响，新增的 `ui_float_bar_mode` 缺省为「完整」。
- 浏览器扩展仍为 0.6.2，本版没有扩展改动；只更新桌面程序时不需要重新加载扩展。升级桌面端后需重启下载器。
- 悬浮条仍不支持鼠标点击穿透，也没有比 158×34 更小的形态。

## 下载与升级

- 安装版：`daw-downloader-v0.8.1-windows-x64-setup.exe`，可选择安装路径并从系统卸载。
- 便携版：`daw-downloader-v0.8.1-windows-x64.zip`。
- 独立扩展：`daw-browser-extension-v0.6.2.zip`（未改动）。
- 校验：安装包附 `.exe.sha256`，ZIP 的 SHA256 见 `SHA256SUMS.txt`。

升级前请正常退出下载器及托盘进程，再运行新版安装包并沿用原安装目录。配置、数据库、下载记录和断点均保留。
