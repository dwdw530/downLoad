# v0.11.0：多选批量操作与按类型自动分目录

发布日期：2026-10-21。桌面版 v0.11.0，浏览器扩展 0.6.2（内容不变）。

本版补齐任务多选与自动分类保存，并将左侧分类树字号适度收小。原有下载、续传、文件安全和用户数据沿用，无需迁移数据库。

## 多选批量操作

- 每张任务卡片增加勾选框，支持“全选当前列表”和清空选择。
- 选择范围为当前分类、搜索及“隐藏已完成”的交集，包含滚动视口外的匹配任务；筛掉的选择会清除，切回不恢复，新任务不自动选。
- 支持批量暂停、开始/继续、重试和删除记录；提交时固定选中任务快照，之后改变筛选不影响已提交范围。
- 暂停处理下载中/等待中；开始处理等待/暂停；重试处理失败/校验失败/取消；不符合状态的任务跳过，开始仍遵守最大并发限制。
- 删除记录只确认一次，不额外删除成品或断点文件；校验中的任务暂时跳过，残留断点仍按原有清扫规则处理。单任务原有删除文件选项不变。
- 操作在后台执行，汇总成功、跳过和失败；一项失败不阻断其余任务。批量期间禁用冲突按钮与右键命令，暂停/删除从提交时即暂缓自动补位。
- 修复状态回调重新启用禁用按钮、批次重复进入、退出后继续操作及后台线程启动失败未释放忙碌等边界问题。

## 按类型自动分目录

- 设置“下载”页新增“按文件类型自动建立子目录”，**默认关闭**。
- 开启后，未手动指定目录的新任务进入默认下载根目录下的“视频、音频、文档、压缩包、程序、其他”之一。
- 直接复用现有扩展名分类，图片、无后缀和未知类型仍归“其他”；不增加内容猜测或事后搬移。
- 按最终有效文件名分类，继续遵循显式名 > Content-Disposition > 重定向地址 > 原地址的优先级。
- **手动指定保存目录优先**，即使填写的是默认根目录，也不自动再加一层分类目录。
- 浏览器右键普通文件与视频同样遵守该开关；视频在最终目录中分配非重名名称，回执读取实际落库文件名，不重复嵌套“视频”。
- 开关和默认目录变化只影响新任务，旧任务、恢复/重试保存路径及 temp_dir 不变；路径预留、同名不覆盖、空间检查、哈希校验和同卷/跨卷发布规则保留。

## 界面细节

- 仅左侧分类项由 18 磅收为 **16 磅**，分组标题由 17 磅收为 **15 磅加粗**。
- 字体家族、侧栏宽度与边距、其他界面的字号及 DPI/缩放不变。

## 保持的边界

- 数据库结构、浏览器扩展与 Native Messaging 协议不变，扩展仍为 0.6.2。
- 下载器自身的未知大小/空文件下载保留；浏览器右键仍拒绝这两类响应，不扩大下载范围。
- 原有平台识别、视频校验、多线程、资源身份续传、总限速及完成后动作继续沿用。
- 本版不包含定时下载、失效链接更新、侧栏滚动、任务分页或批量删除实际文件。
