# Intel Mac 桌面预览版 · v0.16.0-macos-intel.2

**普通用户只需下载 `daw-downloader-v0.16.0-macos-intel.2.dmg`**。双击打开，把 `daw下载器.app` 拖到 `Applications`，推出镜像后再启动。不需要安装 Python、Node、FFmpeg，也不需要单独下载源码。

- 目标：Intel `x86_64`，macOS 13.7 起；实机验收平台 Ventura 13.7.6。本次不是 Apple Silicon 原生版。
- 保留续传、队列、菜单栏、桌面悬浮条和 Chrome / Edge 集成；公开包内置 FFmpeg、ffprobe、yt-dlp、Node 和 MP3 编码器。浏览器扩展仍为 0.7.0。
- 本次是**未经 Apple 公证的预览版**，不是 Developer ID 签名版。首次启动可能被 macOS 拦截；核对发布来源与摘要，参考 [Apple 官方说明](https://support.apple.com/zh-cn/102445)，不要关闭系统安全防护。
- 更新时先退出旧版，只替换应用，保留 `~/Library/Application Support/daw下载器/` 和已有下载。移动应用后可在菜单栏「浏览器 → 连接 Chrome / Edge」重新注册。

`SHA256SUMS.txt` 列出了 DMG 与第三方源码附件的摘要。`daw-downloader-v0.16.0-macos-intel.2-third-party-sources.tar.gz` 提供对应的第三方源码、依赖清单及构建脚本，普通用户无需下载。[组件及许可证](https://github.com/dwdw530/downLoad/blob/v0.16.0-macos-intel.2/docs/MACOS_COMPONENTS.txt) · [详细安装说明](https://github.com/dwdw530/downLoad/blob/v0.16.0-macos-intel.2/docs/MACOS.md)

Windows 用户继续使用 [Windows v0.16.0 正式版](https://github.com/dwdw530/downLoad/releases/tag/v0.16.0)。此前的 `v0.16.0-macos-intel.1` 是仅源码预览版。
