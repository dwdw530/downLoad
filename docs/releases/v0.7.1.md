# v0.7.1：小红书视频笔记下载

> **状态：本版本未单独发布。** 其内容已并入 `v0.7.2`；下方“验证”段中关于测试与 dist 同步的描述与实际不符（详见 v0.7.2 说明）。

发布日期：2026-10-16。桌面版 v0.7.1，浏览器扩展 0.6.1。

## 新功能

- 新增小红书视频笔记详情页下载：在 `xiaohongshu.com` 或 `www.xiaohongshu.com` 的 `/explore/<笔记ID>` 或 `/discovery/item/<笔记ID>`（含 SPA 弹层）页面，悬浮面板和工具栏会出现"小红书 · 最高 1080p"站点条目，点一次即进入桌面下载队列，与 YouTube / X / B 站 / 抖音同构。
- 页面状态读取官方播放器实际使用的签名 MP4 候选（排除小程序水印流，只收 h264/h265），桌面端校验笔记 ID 与页面一致、`.xhscdn.com` 域名、编码、分辨率、无 `range` 参数及总时长后，经 `--load-info-json` + FFmpeg 合并，ffprobe 确认含音视频轨且时长一致后才发布成品。
- 文件名 `小红书-<笔记ID>.mp4`，自动归入站点与视频分组；失败文案可解释（模块未就绪、非视频笔记、未获取笔记信息、清晰度上限、视频已切换、签名地址过期）。

## 边界与兼容

- 不支持图文笔记、LivePhoto、`xhslink.com` 短链、无水印原画、合集批量与直播；只接受不高于所选清晰度上限的档位。
- `xsec_token` 等来源签名参数只留在浏览器内，不写入数据库、日志或任务 URL。
- 播放器与页面状态不一致（如 SPA 内切换笔记）时拒绝下载并提示刷新，不猜测对应关系。
- 既有 YouTube / X / B 站 / 抖音 / HLS / DASH / 右键普通链接下载、剪贴板监视、任务队列 / 续传 / 历史行为不变；共享分类器与安全模型零改动。

## 下载与升级

- 安装版：`daw-downloader-v0.7.1-windows-x64-setup.exe`，可选择安装路径并从系统卸载。
- 便携版：`daw-downloader-v0.7.1-windows-x64.zip`。
- 独立扩展：`daw-browser-extension-v0.6.1.zip`。
- 校验：安装包附 `.exe.sha256`，两个 ZIP 的 SHA256 见 `SHA256SUMS.txt`。

需要同时更新桌面程序（含 BrowserBridge）与扩展：先装桌面端完整包，再在浏览器扩展管理页重新加载扩展并完整刷新已打开的网页。旧桌面端 + 新扩展会提示"小红书模块尚未就绪"，其它站点不受影响；升级与卸载继续保留配置、记录、下载文件和断点。历史 Release、标签和附件保持原样。

## 2026-10-18 真实页面结构变更修复（重要）

用户实测“网页版笔记完全不能下载”后取真实页面状态确认：小红书把 `video.media.stream` 的档位键从 `h264`/`h265` 改为 `EF4`/`EF5`/`EF6`/`EF7`，`videoCodec` 的取值也变成档位名，`masterUrl` 为 `http://`，且分辨率为竖屏（720×1280、1080×1920）。原实现按键名 `h264/h265` 取流、强制 `https`、按 `height` 判档位，四项全部不匹配，导致一条候选都拿不到。

修复：按位置遍历所有档位（不依赖键名）；`http` 仅替换协议为 `https`；档位按短边 `min(宽,高)` 判定；只收 `.mp4`（排除 `.m4s` 分片）；删除基于 `streamType` 数字的水印排除；桌面端改用 `--format <format_id>` 固定已校验的格式（竖屏下 `b[height<=N][ext=mp4]` 恒失败）；补上 `content.js` 兜底分支漏掉的 `await` 与 `background.js` 遗漏的 xhs 二次复核。

同时修正上一轮两处不实记录：`tests/browser_xhs_page.test.mjs` 当时存在缺失 `}` 的语法错误、实际无法执行（此前“JS 测试通过”的表述作废）；`dist/chrome-extension` 当时落后源码，用户加载的是旧脚本。现在源码与 dist 已逐字节一致。

本轮验证：`node --test tests/*.test.mjs` 43 项全过；`python -m pytest tests/ -q` 329 passed + 148 subtests；`yt-dlp --load-info-json --format xhs-0 --simulate` 对竖屏 1080×1920 正常解析。仍需登录态实网 smoke 与用户现场确认。
