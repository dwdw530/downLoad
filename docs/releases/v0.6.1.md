# daw下载器 v0.6.1

Windows x64。本版修复下载安全、续传完整性、任务交互等 9 项问题，并减少保存文件时的额外磁盘复制。浏览器扩展保持 **0.5.0**，旧版本 Release 和附件不替换。

## 下载哪个文件

- [安装包 EXE](https://github.com/dwdw530/downLoad/releases/download/v0.6.1/daw-downloader-v0.6.1-windows-x64-setup.exe)：可选安装路径、快捷方式和系统卸载，包含完整运行环境与视频组件，无需安装 Python。
- `daw-downloader-v0.6.1-windows-x64.zip`：完整便携包，解压后运行 `daw下载器.exe`，勿只复制单个 EXE 用于浏览器下载。
- `daw-browser-extension-v0.5.0.zip`：独立扩展包，本次未更改扩展。
- 安装包的 SHA256 见相邻 `.exe.sha256`；两个 ZIP 的校验值见 `SHA256SUMS.txt`。
- GitHub 自动生成的 Source code 是完整源码，不是 Windows 安装包。窗口标题保留历史 `v1.0`，本次发布标识为 **v0.6.1**。

## 本次修复

1. **保存路径安全**：URL 文件名解码后再次校验，拒绝路径越界、Windows 设备名、ADS 和非法字符。
2. **同名文件保护**：手动、批量与浏览器任务统一分配未占用名称；并发创建时按事务分配，启动前重查，最终写入不覆盖已有文件。
3. **续传完整性**：保存强 ETag / Last-Modified，续传前核对版本和总大小，请求携带条件头，并验证响应的 Content-Range 总大小，避免新旧内容拼接。
4. **关机条件复查**：后台探测和批量待添加也视为未完成工作；倒计时期间新增/重试任务或关闭关机设置会取消旧倒计时，执行关机前再次检查。
5. **暂停与校验隔离**：合并和校验纳入任务工作线程管理；暂停等待旧工作退出，旧会话不能覆盖新状态或误写完成。
6. **恢复顺序**：「继续全部」遵守手动排序，不再被创建时间重新排序。
7. **站点筛选恢复**：等完整任务列表加载后才判断站点是否消失，修复选中站点在重启时误回退为「全部」。
8. **重试排队与反馈**：并发已满时重试进入等待队列，无法启动时给出提示；改名后的文件名同步到卡片和搜索缓存。
9. **速度曲线时间轴**：同秒采样合并、记录单调时钟，按真实时间绘制并计算加权平均，不再将回调数量当作秒数。

## 磁盘写入优化

- **同卷优先安全改名，不复制整份数据**；仅确认为跨卷时才复制，不因权限错误或重名冲突改走覆盖路径。
- **分块直接合并到目标目录的临时文件**，计算校验后安全改名，省去「先在 temp 合并、再复制成品」的一次完整写入。
- 跨卷复制先写目标目录的独立临时文件，全部写完后才发布正式名称。正常暂停、取消或失败清理本次暂存副本，保留源文件/分块用于恢复。
- 普通同卷单线程下载的数据峰值占用接近文件大小的 **1 倍**，多线程约 **2 倍**，相比本轮修复初版的约 2 倍 / 3 倍进一步降低。此估算不含其他任务、已有文件和文件系统开销；跨卷仍需同时保留源与目标副本。

## 升级注意事项

1. 正常退出旧下载器（含托盘），安装新版到原目录，或将完整便携包解压到原目录。
2. 保留原有 `data`、`temp` 和下载文件。安装器升级/卸载不递归清理用户数据。
3. 新版自动为数据库补充可空的资源版本字段。**旧任务没有版本记录、远端文件变化或站点不提供可靠版本信息时，会安全重下，而不是强行复用旧断点。** 无版本信息的普通文件采用单线程完整下载。
4. 扩展仍为 0.5.0，无需为本次升级重装；移动安装目录后需重新注册同目录的浏览器桥接。升级后建议完整刷新已打开的视频网页。

完整步骤见 [Windows 安装包说明](https://github.com/dwdw530/downLoad/blob/main/docs/INSTALLER.md)。
