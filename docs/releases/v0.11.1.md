# v0.11.1：稳定性修复与侧栏字号纠正

日期：2026-10-22。桌面版 v0.11.1，浏览器扩展 0.6.2（内容不变）。

本版修复配置保存、探测中退出和任务操作阻塞界面的问题，并将过大的左侧分类树改为与工具栏相同档位的像素字号；保留 v0.11.0 的多选批量和自动分目录。

## 配置保存保护

- 在配置文件同目录写入随机临时文件，完整写入并刷新落盘、关闭句柄后，再原子替换正式配置。
- 序列化、落盘或替换失败时保留原配置，清理未发布的临时文件；不再先截断旧配置。

## 退出与在途任务

- 退出开始即关闭新添加、启动和恢复入口，将网络探测阶段也纳入等待；迟到探测不能在退出后再创建下载线程。
- 退出前固定在途任务快照，避免探测恰好返回、释放名额后遗漏暂停；相关任务保留为暂停，便于下次继续。
- 探测期间暂停会使旧会话失效；非 Range 活跃流的恢复同样遵守退出门禁。
- 暂停全部的收尾不再覆盖退出标志，迟到的界面结果不访问已销毁窗口。

## 界面响应

- 单任务开始/继续、暂停，以及暂停全部/继续全部改为后台执行，网络探测与线程等待不再阻塞 Tk 主线程。
- 复用已有批量忙碌保护，阻止重复点击、状态回调和右键冲突；结果通过事件队列回主线程。
- 成功结果用状态栏提示，失败保留错误反馈；线程无法启动时释放忙碌，不在 Tk 线程补位联网。

## 左侧分类树字号

- **仅左侧分类项与分组标题统一为 13 逻辑像素，标题只加粗。**
- 原生 Tk 的正数是磅，旧 16pt 约为 21px，不能直接与 CTk 的像素字号比较。现在明确使用负像素值，跟随现有 CTk 控件缩放，避免重复放大。
- 其他字体、240px 侧栏宽度、内外边距、全局 Tk scaling 和系统 DPI 不变。

## 保持的边界

- 数据库结构、浏览器扩展与 Native Messaging 协议不变，扩展仍为 0.6.2。
- 原有多线程、资源身份续传、非覆盖保存、未知大小/空文件、哈希、总限速、视频链路和自动分类规则保留。
- 不新增定时下载、失效链接更新、整站抓取、FTP、侧栏滚动或任务分页。

## 发布前验证

- 最终源码完整 Python/GUI 回归 **564 项通过（728.305 秒）**，浏览器扩展四文件 **43 项通过**。
- 字号测试在独立 Tcl/CTk 进程验证 100%/150% 缩放，避免全量 GUI 用例残留的销毁窗口回调污染；未为通过测试改变产品逻辑。
- 原 dist 双 EXE 重建；包内 5 个修复模块代码对象与当前源码编译一致，分类项/标题均为负像素字号 `-13`，实际 EXE 截图确认侧栏与工具栏同档。
- 正式 EXE 三组冒烟通过：原生按钮、暂停/恢复、关闭重启续传、队列、Range/非 Range、SHA256、历史清理和数据位置隔离。
- Windows 安装包七组验收通过：中文向导、自选中文空格路径、28 项白名单载荷、安装后下载、占用保护、升级/卸载/重装保留数据及原浏览器注册恢复。
- 原配置、数据库、断点与 28 个运行源码文件指纹保持；未新增数据库列或浏览器协议。真实公开站点长期下载、多显示器混合 DPI 未在本版重新实网验收。
