## 下载哪个文件

- **首次使用或升级桌面程序**：下载 `daw-downloader-v0.2.0-windows-x64.zip`。包含下载器、BrowserBridge、浏览器扩展 0.4.0、yt-dlp、FFmpeg/ffprobe、Node 和第三方许可证，无需安装 Python。
- **只更新 Chrome / Edge 插件**：下载 `daw-browser-extension-v0.4.0.zip`。插件需要配合完整包中的桌面下载器和 BrowserBridge 使用，不能独立下载视频。
- `SHA256SUMS.txt`：上述两个 ZIP 的 SHA256 校验值。
- GitHub 自动生成的 `Source code` 文件是源码，不是可直接运行的 Windows 程序。

## 本次提供的功能

- 多线程文件下载、暂停续传、队列、历史记录、代理、限速和文件校验。
- daw 名称与下载箭头图标；清空历史保留事前确认，完成后直接刷新列表。
- Chrome / Edge 网页视频识别与下载按钮，支持 MP4/WebM 直链及 YouTube、X、B站普通视频入口。
- 通用 HLS/M3U8、DASH/MPD 点播下载，复用桌面任务队列及音视频处理组件。

## 使用和升级

1. 将完整 ZIP 解压到固定目录，双击 `daw下载器.exe`。
2. 使用浏览器功能时运行同目录的 `install_browser_bridge.cmd`。
3. 打开 `chrome://extensions/` 或 `edge://extensions/`，开启开发者模式，选择“加载已解压的扩展程序”，加载 `chrome-extension` 文件夹。
4. 刷新视频页面后使用下载按钮。**本版 HLS/DASH 请先启动桌面下载器**；未启动时插件可能提示“流媒体模块尚未就绪”。
5. 升级前完全退出下载器，包括托盘进程；将完整包内容复制到原安装目录，保留原 `data`、`temp`、`downloads`。重启下载器、重新加载扩展并刷新视频页面。移动安装目录后须重新运行桥接安装脚本。

单独更新插件时，解压插件 ZIP，将其中 `chrome-extension` 的内容更新到原扩展目录，再在扩展管理页点击“重新加载”。
