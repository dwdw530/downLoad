# daw 视频下载助手 0.5.2

本次为 Chrome / Edge 浏览器插件更新。修复抖音推荐页识别不到当前视频，以及识别后下载被服务器以 HTTP 403 拒绝的问题。桌面程序沿用现有版本，无需重装下载器。

## 下载与升级

- [插件 ZIP](https://github.com/dwdw530/downLoad/releases/download/extension-v0.5.2/daw-browser-extension-v0.5.2.zip)
- [SHA256 校验文件](https://github.com/dwdw530/downLoad/releases/download/extension-v0.5.2/SHA256SUMS.txt)

1. 将 ZIP 内的 `chrome-extension` 更新到现有插件目录，保留下载器的 `data`、`temp` 和下载文件。
2. 在 `chrome://extensions/` 或 `edge://extensions/` 重新加载 daw 视频下载助手，确认版本为 **0.5.2**。
3. 对已打开的视频标签页按 **Ctrl+F5** 完整刷新。抖音推荐页播放视频后，直接点击“下载视频”。
4. 之前因地址失效或 HTTP 403 失败的任务，请从插件重新添加；旧任务仍保存旧地址。

## 修复内容

- **推荐流识别**：读取新旧播放器绑定的视频 ID 和资源信息，要求它对应当前可见的 video 元素。无需点详情页或最大化，不再依靠详情接口、时长或分辨率猜测当前视频。
- **下载地址**：优先使用该视频提供的同源播放接口，取得服务器实际下发的签名 CDN 地址，修复直接提交播放器备用地址时的 403。地址解析只请求首字节并在收到响应头后停止，整片下载仍由桌面程序完成。
- **切换保护**：悬浮面板和工具栏弹窗重新确认当前视频；视频切换、播放器复用，以及读取授权信息期间切换视频时，旧条目不能继续发送。
- **完整性**：继续拒绝分离音视频轨、分片和未知站点地址，沿用桌面端视频 ID、音视频轨与完整时长校验。
- **打包**：补齐新增抖音页面脚本的发布清单，支持单独生成插件 ZIP 与校验文件。

## 验证

- 源码、正式 `dist` 以及独立 ZIP 解压后的插件均通过 Chromium 扩展回归；覆盖无详情请求的推荐页、新旧播放器、播放接口跳转、同等时长视频切换、旧条目拒绝和分轨过滤。
- YouTube、X、B 站及通用流媒体既有浏览器用例通过；Node 14 项、抖音桌面端 Python 8 项通过。
- 用户真实推荐页验证下载完成并正常播放；成品核对为 **1920×1080 HEVC + AAC、246.410 秒、31,823,532 字节**。

直播、图集、DRM 和仅有分轨的资源不在本次支持范围内；已验证的视频不代表所有受限资源均可下载。
