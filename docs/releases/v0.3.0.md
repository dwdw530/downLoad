# daw下载器 v0.3.0

Windows x64 完整便携版，包含浏览器扩展 0.5.0。重点修复抖音完整视频下载，并明确扩展升级后所有已打开的视频页面都需要完整刷新。

## 下载哪个文件

- **首次使用或从 v0.2.0 升级**：下载 `daw-downloader-v0.3.0-windows-x64.zip`。包含下载器、BrowserBridge、浏览器扩展、yt-dlp、FFmpeg/ffprobe、Node 和第三方许可证，无需安装 Python。
- `daw-browser-extension-v0.5.0.zip`：独立浏览器扩展包，需要配合本版桌面程序和 BrowserBridge。仅升级插件无法给旧 EXE 增加抖音能力。
- `SHA256SUMS.txt`：上述两个 ZIP 的 SHA256 校验值。
- GitHub 自动生成的 `Source code` 是源码，不是 Windows 运行包。窗口内的旧版号 `v1.0` 仍保留，本次 GitHub 发布标识为 `v0.3.0`。

## 本次变化

- 支持抖音普通视频详情页及可确认归属的播放器入口。复用网页已取得的签名详情请求，选择完整 MP4；保留单独音轨、视频轨和未知分片的拦截。
- 复用现有队列、暂停续传及视频组件。完成前校验音轨、视频轨和完整时长，避免将无声单轨或短片段报告为成功。
- 按当前标签页获取授权信息，过滤分区和空名称 Cookie；签名地址及请求上下文沿用本地加密存储，临时文件在子进程结束后清理。
- 冷启动和运行中的桥接统一报告能力，补齐 HLS/DASH 冷启动能力提示。
- X 保留首页浏览时的悬浮和工具栏下载。扩展更新后旧标签页可能失去识别脚本；完整刷新恢复，无需逐条进入帖子详情。
- YouTube、X、B 站既有下载路径保持，相关回归已通过。

## 使用与升级

1. 升级前正常退出下载器，包括托盘进程。将完整包解压到原安装目录，保留原 `data`、`temp`、`downloads`。
2. 首次使用浏览器集成时运行同目录 `install_browser_bridge.cmd`。移动安装位置后也要重新注册桥接；原位置升级无需重装。
3. 在 `chrome://extensions/` 或 `edge://extensions/` 加载或重新加载 `chrome-extension`。
4. **对已经打开的 X、YouTube、B 站、抖音标签页分别按 F5 / Ctrl+F5 完整刷新。** 只在网站内切换视频或点击帖子详情不能代替刷新。
5. 抖音推荐页无法确认当前视频或没有对应详情请求时，打开该视频的详情页并刷新后下载。

发布包不包含用户配置、数据库、Cookie、下载文件、断点文件或本机桥接注册清单。

## 验证与边界

- Python 全量 93 项、JavaScript 14 项通过。
- 源码与正式扩展的 Chromium 回归通过，覆盖 X 首页、YouTube、B 站、抖音、直链、iframe、HLS 识别、未知分片拦截及旧桌面提示。
- 正式双 EXE 实际完成用户提供的抖音视频下载：982×720 H.264 + AAC，580.868934 秒，43167970 字节；冷启动、去重、整片解码和正常退出通过。
- 用户现场确认 X 首页 Ctrl+F5 后悬浮图标恢复。
- 沿用已验收的正式目录组件打包；未重复执行未改动功能的实网下载。既有 HLS/DASH 本地素材验证记录见 v0.2.0 发布说明，本轮没有扩大其验证范围。

本次不承诺所有网站、登录受限作品、所有清晰度、只有分轨的抖音作品、直播或 DRM 均可下载。浏览器验证使用临时配置，真实扩展消息再交隔离桥接/EXE 下载，不冒充用户登录浏览器到已注册桥接的全链路自动验收。
