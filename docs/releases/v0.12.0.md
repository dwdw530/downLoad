# v0.12.0：安全失败原因、暂停分类与重试保护

日期：2026-10-23。桌面版 v0.12.0，浏览器扩展 0.6.2（内容不变）。

本版完善失败恢复和任务信息展示：卡片/详情解释失败原因，左侧增加已暂停分类，未知大小和真实空文件的进度不再混淆，同时修正混合错误与服务器要求等待时的重试行为。

## 失败与暂停原因

- 卡片使用独立原因行，详情同时提供简短建议；启动恢复、状态更新和已打开详情保持一致。
- 仅显示固定中文解释，不回显 URL、签名、Cookie、Authorization、私有地址或用户路径；未知异常使用安全兜底。
- 手动暂停、稍后下载和重启纠偏不显示故障；磁盘空间不足等自动暂停显示原因。
- 新一轮下载清除旧原因，迟到状态/进度不得把完成任务改回下载中。

## 重试与数据保护

- 混合分块错误按 fatal > protocol > transient 处理；403/404/资源版本变化等致命错误不补轮、不降级，收敛同轮工作线程后失败并保留已有字节。
- 普通文件及浏览器受限请求的 429/503 遵守 Retry-After：支持非负整数和 HTTP 日期，等待取原退避与服务器要求的较大值，不叠加、不在外层重建或单线程降级时绕过。
- 三轮上限保持；五分钟窗口从本次首次临时错误开始，内外层/分块共享，只限制新自动重试，不误杀已经成功传输的长下载。
- 拒绝启动前不删除旧块、不截断临时文件、不清进度；正常非 Range 请求获准后仍从零开始，绝不拼接不可信旧数据。
- 等待可暂停、取消、退出；降级失败停止旧进度监控，避免终态后继续写库。
- 手动重试仍核对服务器资源身份，保留字节不等于保证旧断点可以复用。

## 暂停分类与进度

- 左侧状态组增加“已暂停”，带准确计数，复用搜索/隐藏完成交集和原选择持久化；零任务时保留空组。
- 未知大小百分比显示 `--`，保留实际已下载字节与速度；不伪造 0.0%。
- 只有引擎确认 completed 且字节精确 0/0 的真实空文件显示满条和“已完成 · 0 B”。
- 非法/负字节和 NULL 不冒充空文件完成；卡片、首屏与已打开详情一致。

## 保持的边界

- 扩展 0.6.2、Native Messaging、数据库结构、设置项及视频下载链路不变。
- 保留多选批量、默认关闭且手动目录优先的自动分目录、哈希、总限速、资源身份续传及非覆盖保存。
- 不调整其他字号、240px 侧栏、菜单、悬浮条或全局 DPI，不新增定时下载、链接更新、分页或侧栏滚动。
