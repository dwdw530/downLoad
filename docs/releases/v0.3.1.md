# daw下载器 v0.3.1

Windows x64，提供安装包与便携版，包含浏览器扩展 0.5.0。本版重点补齐**运行日志、大文件下载效率和视频失败诊断**；桌面程序与浏览器扩展的下载能力与 v0.3.0 一致。

## 下载哪个文件

- **需要选择安装路径、桌面快捷方式和系统卸载**：[下载安装包 EXE](https://github.com/dwdw530/downLoad/releases/download/v0.3.1/daw-downloader-v0.3.1-windows-x64-setup.exe)，约 148 MiB。包含完整运行环境和视频组件，无需安装 Python。相邻的 `.exe.sha256` 文件用于校验此安装包。
- **需要便携版或覆盖原解压目录升级**：`daw-downloader-v0.3.1-windows-x64.zip`。包含下载器、BrowserBridge、浏览器扩展、yt-dlp、FFmpeg/ffprobe、Node 和第三方许可证。
- `daw-browser-extension-v0.5.0.zip`：独立浏览器扩展包。本版扩展与 v0.3.0 相同，只升级桌面程序时无需重装扩展。
- `SHA256SUMS.txt`：上述两个 ZIP 的 SHA256 校验值。
- GitHub 自动生成的 `Source code` 是源码，不是 Windows 运行包。窗口内的旧版号 `v1.0` 仍保留，本次发布标识为 `v0.3.1`。

## 本次变化

### 1. 新增运行日志（打包版也能留证据）

- 日志默认写入程序目录 `logs/app.log`（2 MB × 3 滚动）；安装到不可写目录时自动回退到 `%LOCALAPPDATA%\LaoWangDownloader\logs\app.log`。
- 打包后的 EXE 没有控制台，此前出错只能靠猜；现在启动、配置、数据库、引擎、合并校验和失败原因都会落盘。需要更详细的内容（含异常堆栈）时设置环境变量 `DAW_LOG_LEVEL=DEBUG`。
- 日志不写入标准输出（stdout 是浏览器桥接的原生消息协议通道），也不记录视频链接与 Cookie。
- 开发环境运行源码时，日志同时输出到终端。

### 2. 视频下载失败诊断更准确

- 失败时把失败原因和 yt-dlp 输出尾部写入日志：链接替换为 `<url>`，Cookie/Authorization 字段替换为 `<redacted>`，避免凭据落盘。
- HTTP 429 限流单独提示「网站限流（HTTP 429），请稍后重试或更换网络或代理」，不再一律报成"网站要求登录或验证"。
- 已知限制：YouTube 对同一出口 IP 存在请求频率限制，触发后需要等待或更换网络/代理；本版不会读取账号 Cookie。

### 3. 大文件下载更省资源

- 分块进度由每 8 KB 写一次数据库改为按 256 KB 或 0.5 秒节流，并在结束、暂停、取消时补报最后一跳。1 GB 文件的写库次数约从 13 万次降到 4 千次。
- 数据库启用 WAL 日志模式（网络盘等不支持时自动退回默认），写入不必等待读锁。
- 进度显示在极端情况下可能比实际文件少几百 KB，不影响断点续传：续传偏移取自临时文件实际大小，合并前也会按内存值收尾。

### 4. 其它

- README、PROJECT_SUMMARY 与架构设计文档按当前实现校正（平台约束、项目结构、状态机、数据模型、日志与排障）。

抖音详情页完整 MP4、X 首页悬浮下载、YouTube、B 站、HLS/DASH 与直链下载，以及队列、暂停续传、限速、代理、历史记录与系统托盘等能力与 v0.3.0 相同，未做改动。

## 使用与升级

安装版：运行 `*-setup.exe`，选择当前用户有写入权限的安装目录。升级前退出下载器（含托盘进程），沿用原目录即可。卸载从 Windows「设置 → 应用 → 已安装的应用」进行，保留配置、下载记录、下载文件和断点。浏览器扩展仍需手动加载安装目录中的 `chrome-extension`。完整构建、安装、升级与卸载步骤见 [安装包操作说明](https://github.com/dwdw530/downLoad/blob/main/docs/INSTALLER.md)。

便携版及浏览器扩展：

1. 升级前正常退出下载器，包括托盘进程。将完整包解压到原安装目录，保留原 `data`、`temp`、`downloads`。
2. 首次使用浏览器集成时运行同目录 `install_browser_bridge.cmd`。移动安装位置后也要重新注册桥接；原位置升级无需重装。
3. 在 `chrome://extensions/` 或 `edge://extensions/` 加载或重新加载 `chrome-extension`。
4. 对已经打开的 X、YouTube、B 站、抖音标签页分别按 F5 / Ctrl+F5 完整刷新。
5. 抖音推荐页无法确认当前视频或没有对应详情请求时，打开该视频的详情页并刷新后下载。

发布包不包含用户配置、数据库、Cookie、下载文件、断点文件或本机桥接注册清单。

## 验证与边界

- Python 全量 111 项、JavaScript 14 项测试通过（含新增的分块进度节流 6 项与视频失败诊断 4 项）。
- 打包后的 EXE 在独立目录实测：启动即写入日志、数据库为 WAL 模式、正常退出且无 `.wal`/`.shm` 残留。
- 真实使用验证：1080p 视频实际下载完成（431,515,380 字节，H.264 1920×1080 + AAC，时长 1656.81 秒），MD5 入库，ffprobe 校验通过。
- 失败样本复现：YouTube 限流（HTTP 429）时，桌面端、yt-dlp 命令行与不同 player client 均返回同样错误，确认与程序无关；更换出口 IP 后下载立即恢复。
- 沿用已验收的正式组件打包，未重复执行未改动功能的实网下载。浏览器验证使用临时配置，不冒充用户登录浏览器到已注册桥接的全链路验收。

本版不承诺所有网站、登录受限作品、所有清晰度、只有分轨的抖音作品、直播或 DRM 均可下载。
