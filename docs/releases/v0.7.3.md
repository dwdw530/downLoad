# v0.7.3：设置页支持临时文件目录，下载写入不再固定占用系统盘

发布日期：2026-10-20。桌面版 v0.7.3，浏览器扩展 0.6.2（未改动）。

## 本次改动

### 临时文件目录可配置，且保存后立即生效

以前下载器把分块、合并和视频下载的临时文件固定写在程序目录下的 `temp/`，即使“默认下载目录”指向 U 盘或移动硬盘，数据也要先完整写进程序所在磁盘，校验后再复制到目标盘。对系统盘是 SSD 的用户来说，等于每下载一个文件都先白白写一遍 SSD。

现在“设置 → 下载 → 临时文件目录”可以直接选择其他磁盘（例如 `E:\daw-temp`），保存后立即生效：

- 新添加的任务直接使用新目录，**不需要重启程序**。
- 没有断点数据的排队任务会同步改写分块路径，下一个任务就落在新目录。
- 已经有下载字节的任务继续使用原临时目录，不搬移大文件、不破坏断点。
- 临时目录与下载目录在同一磁盘时，完成后仍是改名发布，不复制；跨磁盘时才会多一次完整复制。
- 保存前会创建目录并做一次写探针。U 盘未插、盘符变化或目录只读会当场报错，不会等下载到一半才失败。
- 输入框为空时回退到默认 `temp`，不再把空字符串解析成程序根目录；支持 `%USERPROFILE%` 等环境变量。未修改时保留配置里原来的相对写法，不把程序目录写死进 `config.json`。

### 设置页改为标签页，缩短窗口

设置项增加后单页过长（520×800 仍接近占满屏幕），现改为「下载 / 其他」两个标签页，窗口调整为 560×520：

- 下载：默认下载目录、临时文件目录、下载线程数、同时下载任务数、速度限制、请求超时、代理设置。
- 其他：下载完成后动作、剪贴板监视、主题。
- 线程数和同时下载任务数的数值改为紧贴滑块右侧，不再被推到窗口最右边。

## 行为说明与边界

- 程序本体、数据库和日志仍在安装目录（通常是系统盘），但每部影片只有 KB 级写入，可忽略。
- 已暂停/失败且已有部分数据的任务不会自动迁移到新目录；需要它们也换盘时，删除任务重下即可。
- 临时目录设在 U 盘/移动硬盘时，请保持磁盘连接并固定盘符；拔出或盘符变化会导致下载失败。
- 下载完成后复制/改名、断点续传、同名保护、哈希校验等既有规则未改动。
- 浏览器扩展仍为 0.6.2，本版没有扩展改动；只更新桌面程序时不需要重新加载扩展。升级桌面端后需重启下载器。

## 下载与升级

- 安装版：`daw-downloader-v0.7.3-windows-x64-setup.exe`，可选择安装路径并从系统卸载。
- 便携版：`daw-downloader-v0.7.3-windows-x64.zip`。
- 独立扩展：`daw-browser-extension-v0.6.2.zip`（未改动）。
- 校验：安装包附 `.exe.sha256`，ZIP 的 SHA256 见 `SHA256SUMS.txt`。

升级前请正常退出下载器及托盘进程，再运行新版安装包并沿用原安装目录。配置、数据库、下载记录和断点均保留。

## 已知边界

- 临时目录切换只影响新任务和无断点数据的排队任务；正在下载或已有断点的任务继续使用原目录。
- 跨磁盘临时目录仍需保持磁盘在线；程序不会自动迁移旧临时文件。
- 该版不包含站点适配变更，YouTube / B 站 / 抖音 / 小红书 / X 的行为与 v0.7.2 一致。
