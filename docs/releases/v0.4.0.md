# daw下载器 v0.4.0

Windows x64，提供安装包与便携版，浏览器扩展仍为 0.5.0（本版未改动扩展）。本版重点是**界面与交互**：任务卡片信息更完整、支持批量添加、可「稍后下载」、任务列表可搜索并隐藏已完成，以及下载完成后可自动打开文件/文件夹或关机；主窗口启动时按屏幕居中。

## 下载哪个文件

- **需要选择安装路径、桌面快捷方式和系统卸载**：[下载安装包 EXE](https://github.com/dwdw530/downLoad/releases/download/v0.4.0/daw-downloader-v0.4.0-windows-x64-setup.exe)，约 148.5 MiB。包含完整运行环境和视频组件，无需安装 Python。相邻的 `.exe.sha256` 文件用于校验此安装包。
- **需要便携版或覆盖原解压目录升级**：`daw-downloader-v0.4.0-windows-x64.zip`。包含下载器、BrowserBridge、浏览器扩展、yt-dlp、FFmpeg/ffprobe、Node 和第三方许可证。
- `daw-browser-extension-v0.5.0.zip`：独立浏览器扩展包。本版扩展与 v0.3.1 完全相同，只升级桌面程序时无需重新安装扩展。
- `SHA256SUMS.txt`：上述两个 ZIP 的 SHA256 校验值。
- GitHub 自动生成的 `Source code` 是源码，不是 Windows 运行包。窗口标题里的旧版号 `v1.0` 仍保留，本次发布标识为 `v0.4.0`。

## 本次变化

### 1. 任务卡片信息更完整

- 每张任务卡改为两行：第一行是进度条 + 百分比 +「文件位置」按钮；第二行显示 **已下载 / 总大小、剩余时间、速度、状态**。
- 剩余时间只在下载中且速度大于 0 时显示，其它情况显示 `--`；总大小未知时显示 `X / 未知`，不再猜一个数字。

### 2. 批量添加

- 「添加任务」的链接输入框改为多行：**每行一个链接**，空行忽略，同一批内重复链接自动去重。
- 多条链接在后台逐条添加（每条都要先探测地址），完成后弹一个汇总框：成功数量、跳过重复数量、失败数量（最多列出 3 条原因）。
- 单条链接保持原来的即时添加与提示；文件校验（MD5/SHA256）只在单条链接时可用，批量时自动置灰。
- 多行输入框内回车是换行，提交用 Ctrl+Enter。

### 3. 开始下载 / 稍后下载

- 添加对话框提供两个提交按钮：「开始下载」立即进入下载队列；「稍后下载」只把任务加入列表，等你手动点「▶ 继续」。
- 「稍后下载」的任务不会占用并发槽位，也不会被队列自动拉起。

### 4. 搜索与隐藏已完成

- 任务列表上方新增搜索框（按文件名或链接匹配，不区分大小写）和「隐藏已完成」勾选项，右侧显示 `显示 N / M`。
- 筛选无结果时显示「没有匹配的任务」；「隐藏已完成」会写入 `config.json` 的 `ui_hide_completed` 并在重启后保留，搜索词不保存。

### 5. 下载完成后动作（可选，默认全关）

- 设置里新增「下载完成后」：**打开文件、打开所在文件夹、全部下载完成后关机**。
- 只有校验通过（`completed`）才触发，哈希校验失败不触发；打开文件夹会定位到文件。
- 选择关机时，如果队列里还有下载中/等待/校验中的任务，会等最后一个完成再弹出 60 秒倒计时确认框；点「取消」或直接关闭该窗口都不会关机。

### 6. 主窗口启动居中

- 主窗口打开时按屏幕居中（尺寸仍为 900×600）。已按 200% DPI 实测：窗口物理外框落在 (700,400)，中心与屏幕中心偏差约 (+13,+35) 像素，属边框与取整误差。

### 其它

- README、PROJECT_SUMMARY 与架构设计文档按当前实现校正（新增配置项、卡片与筛选说明、批量添加流程）。

队列调度、多线程分块、断点续传、限速、代理、历史记录、托盘，以及抖音详情页完整 MP4、X 首页悬浮下载、YouTube、B 站、HLS/DASH 与直链下载等能力与 v0.3.1 相同，未做改动。

## 使用与升级

安装版：运行 `*-setup.exe`，选择当前用户有写入权限的安装目录。升级前退出下载器（含托盘进程），沿用原目录即可。卸载从 Windows「设置 → 应用 → 已安装的应用」进行，保留配置、下载记录、下载文件和断点。浏览器扩展仍需手动加载安装目录中的 `chrome-extension`。完整构建、安装、升级与卸载步骤见 [安装包操作说明](https://github.com/dwdw530/downLoad/blob/main/docs/INSTALLER.md)。

便携版：

1. 升级前正常退出下载器，包括托盘进程。将完整包解压到原安装目录，保留原 `data`、`temp`、`downloads`。
2. 本版未改动扩展，原有浏览器集成无需重装；若移动了安装位置，需要重新运行同目录 `install_browser_bridge.cmd` 注册桥接。
3. 升级桌面程序后建议对已打开的 X、YouTube、B 站、抖音标签页按 F5 / Ctrl+F5 完整刷新，避免旧页面脚本残留导致悬浮按钮异常。

发布包不包含用户配置、数据库、Cookie、下载文件、断点文件或本机桥接注册清单。
