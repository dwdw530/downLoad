### A. 固定的产品行为

- 复用 CTk 卡片，文件名旁加勾选，搜索下方加紧凑批量栏；字号/主题/侧栏/菜单/悬浮条保持。
- 全选当前分类、搜索、隐藏已完成的交集，包含滚动视口外的匹配任务，不包括被筛掉的任务。
- 筛掉选择就清除，切回不恢复；新任务不自动选。提交时复制有序 ID 快照，后台不随筛选或新增改变范围。
- 暂停处理 downloading/pending；开始处理 pending/paused；重试处理 failed/verify_failed/cancelled；其他跳过。
- **批量入口叫删除记录**，一次确认，不额外删除成品或断点文件，原取消流程的会话暂存/凭据清理保持，verifying 跳过；单任务原有删文件选项保持。
- 汇总成功/跳过/失败；单项失败不阻断其余，不逐项弹框。
- `auto_classify_downloads` 默认 False；子目录沿用视频/音频/文档/压缩包/程序/其他六类，图片仍按原规则归其他，不加新分类。
- 按最终有效文件名判类；手动目录原样使用，即使与默认根相同。旧任务不重分、不迁移，temp_dir 不变。
- 浏览器普通右键及视频也遵守默认分目录，只改桌面 bridge 的目录调用，不改扩展/Native 协议/安全校验。

### B. 实现与重点保护

1. file_utils 增加纯目录函数，引擎在最终取名后、空间检查和事务预留前接入；不做下载完成后搬文件。
2. 普通右键当前总传默认 save_path，需改成无显式目录调用，让引擎按服务端文件名分类。
3. 视频 bridge 在最终分类目录重名预选，显式传引擎后不二次分类；回执取实际落库文件名，不返回并发改名前的旧名。
4. TaskManager 增加轻量 batch_operate，返回设计规定三类结果，复用单任务接口，禁止拿 pause_all/retry_failed 冒充选中操作。
5. 暂停/删除时暂缓补位，结束恢复；开始/重试不能被自己的门禁挡住。hold 与 pause_all/shutdown 共存，不 finally 一律清退出标志。
6. 阻塞操作放后台，经 `_ui_events` 回 Tk；worker 不读控件/弹窗，不拿 manager 锁等待会回调取同锁的线程。
7. 批量计入 activity generation / get_activity_state；UI 提交到 worker 启动间隙也算工作，防止误关机。连点只一批，退出后不启动下一项或操作销毁窗口。
8. 成功删记录后复用小方法清卡片、详情、速度和选择；失败保留。不要重写原单任务实际文件删除流程。
9. 设置接齐加载、保存、失败回滚、重置、运行时回调；成功仍用状态栏提示。
10. 保持文件名校验、强验证器续传、路径事务、启动重查、非覆盖、空间预检和 v0.10.0 边界；浏览器未知大小/空文件仍拒绝。
