# daw下载器

Windows 桌面下载器，支持多线程下载、断点续传、任务队列，以及浏览器视频和普通文件链接下载。

> **目前仅支持 64 位 Windows。** 使用安装包或便携版无需安装 Python。

## 主要功能

- 支持 1–16 线程分块下载、暂停续传、并发队列和失败分块重试。
- 支持多行批量添加、任务搜索、按状态/文件类型/站点筛选，以及勾选后的批量操作。
- 支持按文件类型自动建立保存子目录，也可手动指定保存位置。
- 显示进度、速度和剩余时间，双击任务卡片可查看详情与速度曲线。
- 支持 MD5/SHA256 文件校验，用于检查下载文件是否与预期一致；保存时不覆盖已有文件。
- 支持代理、速度限制、下载历史、剪贴板监视和系统托盘。
- 提供深色/浅色/跟随系统主题、窗口透明度，以及完整/迷你桌面悬浮条。
- 可设置完成后打开文件或文件夹，以及全部任务成功后退出或关机；默认不执行完成后动作。

## 快速使用

1. 安装或完整解压发布包，运行 `daw下载器.exe`；源码仓库中的便携入口是 `dist/daw下载器.exe`。
2. 在“设置”中选择默认下载目录和临时文件目录。使用 U 盘或移动硬盘时，确认设备已连接且盘符正确。
3. 点击“添加任务”，粘贴下载链接，多条链接每行一个；选择“开始下载”或“稍后下载”，单条任务可填写预期校验值。
4. 下载过程中可暂停、继续或重试；右键任务卡片可打开保存位置、调整顺序或删除记录。

## 浏览器扩展

扩展支持 MP4/WebM 视频直链、HLS/DASH 流媒体（分片传输的视频），以及 YouTube、X、B 站、抖音和小红书的普通视频。视频清晰度可选最高 480p、720p、1080p，实际以源视频为准。

1. 安装版安装时选择连接浏览器；便携版运行发布目录内的 `install_browser_bridge.cmd`。
2. 打开 Chrome 的 `chrome://extensions/` 或 Edge 的 `edge://extensions/`，开启开发者模式，加载发布目录内的 `chrome-extension/` 文件夹。
3. 完整刷新已经打开的视频页面并播放视频，再点击播放器上的“下载视频”或扩展资源列表中的下载按钮。
4. 普通文件链接可右键选择“使用 daw 下载器下载此链接”；扩展不会自动接管浏览器下载。

扩展尚未上架 Chrome 商店。不绕过 DRM（视频版权保护）或网站访问控制，不支持直播录制，也不保证所有网站或登录受限视频都能下载。小红书仅支持视频笔记，不支持图文、LivePhoto 或短链。完整范围、权限和安装方法见 [浏览器集成说明](docs/BROWSER_VIDEO.md)。

## 注意事项

- 续传取决于服务器支持和资源版本。远端文件已变化或无法确认版本时会安全重下，不拼接新旧文件。
- 目标盘或临时盘不可用时不会启动下载，并明确提示磁盘不可用；接回设备并恢复原盘符后可重试。
- 修改默认下载目录只影响新任务，已有断点不会随临时目录设置迁移；旧任务更换保存位置需重新添加。
- 普通文件总限速对所有普通任务合计生效，视频任务仍按单任务限速；速度也受网络和服务器限制。
- 无大小或零字节普通文件可在下载器内添加，浏览器普通文件入口仍会拒绝这类文件。
- 批量删除只移除任务记录，不删除下载文件或断点；单任务删除可选择同时删除文件。
- 配置和数据库位于程序目录的 `data/`，日志默认位于 `logs/app.log`；不可写时日志回退到 `%LOCALAPPDATA%\LaoWangDownloader\logs\app.log`。反馈问题时请提供报错和相关日志，并遮蔽链接或凭据。

## 源码开发与文档

源码运行需要 Windows 和 Python 3.10+，项目构建与 GUI 验证使用 `py310_env` 环境。在项目根目录执行：

```bash
pip install -r requirements.txt
python main.py
```

运行 Python 测试：

```bash
python -B -m unittest discover -s tests -v
```

GUI 和 EXE 验收需要可交互的桌面；详细测试范围与结果留在对应版本说明中。
